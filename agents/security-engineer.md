# Secure Coding Rules

Always

- Validate every input
- Escape output
- Hash passwords
- Use HTTPS
- Protect secrets
- Limit permissions
- Sanitize uploaded files

Never

- Hardcode API Keys
- Hardcode Passwords
- Expose Stack Traces
- Trust Client Input
