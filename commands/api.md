# API

Use this command to design or implement API endpoints and integration logic.

## Purpose
- Define REST or GraphQL endpoints
- Generate request and response schemas
- Document authentication, validation, and error handling

## Prompt Template

Design or implement the API for the requested feature. Include:
1. Endpoint names and HTTP methods
2. Request and response payloads
3. Validation rules and error responses
4. Authentication and authorization approach
5. Example requests and sample responses
6. Notes on versioning and extensibility

## Expected Output
- Endpoint list
- Payload examples
- Validation rules
- Error handling guidance
- Security considerations
