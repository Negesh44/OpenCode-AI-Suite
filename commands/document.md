# Document

Use this command to create or improve documentation for code, features, or systems.

## Purpose
- Generate technical documentation
- Improve onboarding and maintainability
- Clarify architecture, APIs, and workflows

## Prompt Template

Create or improve documentation for the requested topic. Include:
1. Summary of the feature or system
2. Setup and prerequisites
3. Usage instructions
4. Architecture or workflow explanation
5. Configuration and environment details
6. Troubleshooting and maintenance notes

## Expected Output
- Clear markdown documentation
- Step-by-step instructions
- Relevant examples
- Maintenance notes
