# Test

Use this command to design, create, or improve tests for software.

## Purpose
- Add unit, integration, or end-to-end tests
- Improve test coverage and reliability
- Validate behavior against requirements

## Prompt Template

Create or improve tests for the requested feature or module. Include:
1. Scope of testing
2. Test cases and scenarios
3. Unit or integration test strategy
4. Mocking or fixture requirements
5. Expected results and edge cases
6. Test execution guidance

## Expected Output
- Test plan
- Test cases
- Example test code
- Coverage and validation notes
