Develop a production-ready feature using multiple specialized agents.

# Step 1 — Requirement Analysis

Agent

Software Architect

Responsibilities

- Understand requirements
- Ask clarification questions
- Design architecture
- Design APIs
- Design database
- Define folder structure
- Create implementation roadmap

Deliverables

- Architecture
- API Design
- Database Design
- Roadmap

---

# Step 2 — Implementation

Agent

Full Stack Engineer

Responsibilities

- Implement backend
- Implement frontend
- Follow coding standards
- Follow architecture
- Write production-ready code

Deliverables

- Backend
- Frontend
- Tests
