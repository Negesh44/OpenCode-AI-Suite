# /review

## Purpose

Perform a complete production-ready code review.

---

## Workflow

1. Analyze changed files.
2. Understand feature purpose.
3. Review architecture.
4. Review code quality.
5. Review security.
6. Review performance.
7. Review database.
8. Review frontend.
9. Review backend.
10. Review testing.
11. Generate final report.
