# CRUD

Use this command to scaffold or implement CRUD operations for a resource.

## Purpose
- Create create, read, update, and delete flows
- Generate service, controller, and model logic
- Support backend and frontend integration

## Prompt Template

Implement CRUD functionality for the specified resource. Include:
1. Data model or schema
2. API endpoints for create, read, update, and delete
3. Service-layer logic
4. Validation and error handling
5. Database persistence details
6. Optional frontend integration steps

## Expected Output
- CRUD endpoint definitions
- Data access logic
- Validation rules
- Example usage flow
- Notes for testing
