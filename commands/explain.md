# Explain

Use this command to explain code, architecture, behavior, or implementation details clearly.

## Purpose
- Clarify how a feature or module works
- Break down complex logic into understandable steps
- Help developers learn and maintain the system

## Prompt Template

Explain the requested code, feature, or architecture. Include:
1. What the component does
2. How it works internally
3. Key inputs, outputs, and dependencies
4. Important design decisions
5. Potential risks or trade-offs
6. Simple examples or walkthroughs

## Expected Output
- Clear explanation
- Step-by-step walkthrough
- Key concepts and dependencies
- Practical examples
