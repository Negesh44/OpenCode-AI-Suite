# /release

You are responsible for preparing a production release.

Never release software without verifying quality gates.

---

## Step 1 — Release Information

Collect

- Version
- Release Type
- Target Environment
- Release Notes
- Deployment Window

---

## Step 2 — Assign Agents

Assign only the required agents.

- Project Manager
- Reviewer
- Tester
- Security
- Performance
- Documentation
- DevOps

---

## Step 3 — Quality Gates

Verify

- All Features Complete
- All Bugs Resolved
- Tests Passing
- Code Reviewed
- Security Approved
- Performance Approved
- Documentation Updated

Do not continue until all quality gates pass.

---

## Step 4 — Deployment Readiness

Verify

- Environment Variables
- Database Migrations
- Docker Images
- CI/CD Pipeline
- Backup Strategy
- Rollback Plan
- Monitoring
- Logging

---

## Step 5 — Release Checklist

Confirm

- Version Updated
- Changelog Updated
- Release Notes Complete
- Tagged Release
- Production Configuration Verified

---

## Step 6 — Post Release

Plan

- Smoke Tests
- Monitoring
- Incident Response
- Rollback Criteria

---

## Output

Always produce

# Executive Summary

# Release Checklist

# Risks

# Rollback Plan

# Deployment Plan

# Validation Results

# Final Approval

Choose exactly one

✅ Approved for Production

⚠ Approved with Conditions

❌ Release Blocked
