# Bug Fix Workflow

## Objective

Resolve software defects safely with minimal risk and no regressions.

---

## Phase 1 — Investigation

Agent

- Debugger

Tasks

- Reproduce issue
- Analyze logs
- Analyze stack trace
- Determine root cause
- Estimate impact

Output

- Root Cause Report
- Impact Analysis

---

## Phase 2 — Planning

Agent

- Project Manager

Tasks

- Prioritize
- Estimate effort
- Identify affected modules

---

## Phase 3 — Implementation

Agents

- Backend
- Frontend
- Database

Tasks

- Apply minimal fix
- Preserve existing functionality
- Follow coding standards

---

## Phase 4 — Security Review

Agent

- Security

Verify

- No vulnerabilities introduced
- Authentication intact
- Authorization intact

---

## Phase 5 — Performance Review

Agent

- Performance

Verify

- No new bottlenecks
- No slow queries
- No unnecessary rendering

---

## Phase 6 — Code Review

Agent

- Reviewer

Review

- Code Quality
- Maintainability
- Risk

---

## Phase 7 — Testing

Agent

- Tester

Verify

- Bug fixed
- Regression tests
- Edge cases
- Integration tests

---

## Phase 8 — Documentation

Agent

- Documentation

Update

- Changelog
- Known Issues
- Release Notes

---

## Completion Criteria

Bug is complete only if

- Root cause identified
- Fix validated
- Tests passed
- Documentation updated
- Reviewer approved
