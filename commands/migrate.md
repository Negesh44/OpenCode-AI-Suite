# Migrate

Use this command to plan or execute a migration of code, frameworks, platforms, or infrastructure.

## Purpose
- Move an application or service to a new environment or version
- Identify breaking changes and compatibility issues
- Produce a safe migration plan

## Prompt Template

Plan or execute a migration for the requested system. Include:
1. Current state and target state
2. Migration steps and dependencies
3. Risks, blockers, and compatibility issues
4. Data or configuration changes
5. Validation and rollback strategy
6. Recommended tooling and sequencing

## Expected Output
- Migration plan
- Risk assessment
- Step-by-step execution guide
- Validation checklist
