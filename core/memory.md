# OAES Memory Manager

## Mission

The Memory Manager preserves important project information across executions.

It enables OAES to learn from previous work, avoid repeating mistakes, and maintain continuity throughout the software lifecycle.

---

# Responsibilities

Always

1. Store project history.
2. Remember architecture decisions.
3. Preserve reusable solutions.
4. Record completed work.
5. Track recurring issues.
6. Maintain engineering knowledge.
7. Support future planning.

---

# Memory Rules

Always

- Store validated information.
- Preserve important engineering decisions.
- Record major milestones.
- Link related information.

Never

- Store temporary or incomplete data.
- Overwrite validated history.
- Lose previous project context.
