# Scaffold

Use this command to generate starter code, structure, or boilerplate for a new feature or project.

## Purpose
- Create initial project structure
- Generate reusable templates and skeleton files
- Speed up development setup

## Prompt Template

Scaffold the requested feature or project structure. Include:
1. Project or module structure
2. Base files and folders to create
3. Initial configuration and dependencies
4. Sample code or starter implementation
5. Naming conventions and organization rules
6. Suggested next steps

## Expected Output
- Starter project structure
- Boilerplate files
- Initial implementation skeleton
- Setup guidance
