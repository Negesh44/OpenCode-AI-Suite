# Feature Workflow

## Objective

Deliver a complete feature from planning to production using coordinated engineering agents.

---

## Phase 1 — Planning

Agent

- Project Manager

Output

- Requirements
- Assumptions
- Milestones
- Risks
- Timeline

---

## Phase 2 — Architecture

Agent

- Architect

Output

- System Design
- Folder Structure
- APIs
- Database Design
- Component Design

---

## Phase 3 — Development

Agents

- Backend
- Frontend
- Database

Tasks

- Implement feature
- Add validation
- Handle errors
- Maintain coding standards

---

## Phase 4 — Security

Agent

- Security

Review

- Authentication
- Authorization
- Input Validation
- Secrets
- Vulnerabilities

---

## Phase 5 — Performance

Agent

- Performance

Review

- Query Optimization
- API Response Time
- Rendering Performance
- Resource Usage

---

## Phase 6 — Code Review

Agent

- Reviewer

Review

- Code Quality
- Maintainability
- SOLID
- DRY
- Production Readiness

---

## Phase 7 — Testing

Agent

- Tester

Verify

- Unit Tests
- Integration Tests
- Regression Tests
- Edge Cases

---

## Phase 8 — Documentation

Agent

- Documentation

Produce

- README
- API Docs
- Changelog
- Deployment Notes

---

## Completion Criteria

The feature is complete only if:

- All reviews pass
- Tests pass
- Documentation updated
- Security approved
- Performance approved
- Production ready
