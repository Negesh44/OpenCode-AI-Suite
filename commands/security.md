# Security

Use this command to review, harden, or design secure systems.

## Purpose
- Identify vulnerabilities and insecure patterns
- Recommend secure implementation practices
- Support threat modeling and mitigation planning

## Prompt Template

Review or improve the security of the requested system. Include:
1. Threats and attack surfaces
2. Authentication and authorization approach
3. Input validation and data protection
4. Secrets and configuration handling
5. Recommended security controls
6. Testing and verification steps

## Expected Output
- Security review summary
- Risks and mitigations
- Secure implementation guidance
- Verification checklist
