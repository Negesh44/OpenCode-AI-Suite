# Design

Use this command to design a system, component, or feature with clear architecture guidance.

## Purpose
- Define system structure and responsibilities
- Propose components, flows, and interfaces
- Produce implementation-ready design notes

## Prompt Template

Design the requested feature or system. Include:
1. Overview and goals
2. High-level architecture
3. Main components and responsibilities
4. Data flow and interactions
5. Interface contracts and API boundaries
6. Trade-offs and scalability considerations

## Expected Output
- Architecture overview
- Component breakdown
- Interaction flow
- Design trade-offs
- Implementation guidance
