# Optimize

Use this command to improve performance, maintainability, or efficiency.

## Purpose
- Improve runtime behavior and responsiveness
- Reduce complexity or resource usage
- Identify bottlenecks and improvement opportunities

## Prompt Template

Optimize the requested component or system. Include:
1. Current bottlenecks or inefficiencies
2. Proposed improvements
3. Expected impact on performance or maintainability
4. Trade-offs and risks
5. Implementation steps
6. Verification approach

## Expected Output
- Optimization recommendations
- Implementation strategy
- Performance impact notes
- Validation plan
