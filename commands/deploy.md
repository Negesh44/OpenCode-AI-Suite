# Deploy

Use this command to prepare deployment steps for an application or service.

## Purpose
- Generate deployment strategy and infrastructure guidance
- Create CI/CD and environment configuration plans
- Highlight runtime requirements and dependencies

## Prompt Template

Prepare a deployment plan for the project. Include:
1. Target environment and hosting options
2. Build and release steps
3. Environment variables and secrets
4. Database and service dependencies
5. Monitoring, logging, and rollback strategy
6. Security and compliance considerations

## Expected Output
- Deployment checklist
- Build and release flow
- Environment configuration guide
- Operational recommendations
