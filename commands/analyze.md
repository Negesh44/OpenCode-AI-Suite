# Analyze

Use this command to inspect a codebase and produce a clear technical summary.

## Purpose
- Review project structure and architecture
- Identify key modules, dependencies, and patterns
- Highlight risks, improvements, and next steps

## Prompt Template

Analyze the repository and provide:
1. Overview of the project
2. Main technologies and frameworks
3. Key folders and responsibilities
4. Current architecture and design patterns
5. Risks, technical debt, and improvement opportunities
6. Suggested next actions

## Expected Output
- Short project summary
- Architecture summary
- Main risks and recommendations
- Prioritized action list
